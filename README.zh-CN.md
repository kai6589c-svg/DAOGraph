# DAOGraph 中文说明

_基于“势”的自适应 Agent 图架构，保留最少的执行约束。0.1.0 为 alpha 版本。_

---

DAOGraph 将你提出的控制思想实现为一个独立 Python 框架：宿主定义目标与
边界，系统从事实评估局势，再根据局势生成当前执行图。每执行一个任务，
系统就重新评估、重新规划。

## 🎯 三个核心模块

| 英文模块 | 作用 |
| --- | --- |
| `graph` | 执行瞬时 DAG、合并状态、流式事件、暂停和恢复 |
| `situation` | “势”：风险、不确定性、紧迫度、可逆性、资源压力、信任 |
| `constraints` | 最少约束：步数上限、节点权限、人工确认和可选硬规则 |

目标属于 `DAOGraph` 的只读配置。没有另设角色系统、治理平面、策略引擎、
工具适配器和预算模块。规划器是一个函数，工具是普通同步或异步函数。

## 🔄 动态执行图

初始计划可以是 `research → answer`。研究返回互相矛盾的来源后，
评估器提高 `uncertainty`，规划器将未执行的路径改为
`research → verify → answer`。已经完成的 `research` 不会重复执行。

这由 `examples/adaptive_research.py` 演示；不是预先固定一个包含全部节点的图。
规划器可以插入节点、删除未执行任务、改变依赖，也可以用新任务 id 再调用
同一工具。运行时只允许调用宿主注册的节点。

每次规划生成 DAG，运行时按声明顺序执行一个就绪任务，然后立即重新评估。
0.1.0 支持分支和汇合依赖，单次运行内暂时顺序执行。

## 🚀 本地运行

需要 Python 3.11 或更新版本，在仓库根目录运行：

```bash
python -m pip install -e .
python examples/adaptive_research.py
python examples/approval.py
python examples/async_tools.py
```

核心没有第三方运行时依赖。不需要 API key 就能验证架构。
可以把示例中的确定性函数换成真实模型、搜索、数据库或 API 调用。

## 🛡️ 目标和约束

目标、节点注册表、约束配置不可由状态更新改写。默认最多执行 32 个任务。
节点权限白名单可选；额外硬规则通过返回 `Decision` 的函数添加。

读操作不会因为整体风险较高而自动暂停。带副作用的节点，在风险达到 0.7
或可逆性低于等于 0.3 时暂停。节点本身也可以声明风险、可逆性或必须确认。
硬拒绝不会被批准覆盖，状态中的 `approved=True` 不具备授权作用。

暂停检查点可转成 JSON。宿主批准指定任务后恢复，系统再次识势、检查边界，
执行原来待批准的动作。恢复时若局势变化且仍需确认，会产生新的批准请求。

检查点属于可信宿主数据。运行时不提供身份认证、签名审批、跨进程的单次消费
保证或 Python 沙箱。真实外部操作需要宿主保护检查点、管理批准人、串行恢复，
并给工具提供幂等键。这些是明确的实现边界。

## 📊 势如何形成

默认评估器读取显式 `state["signals"]`，不会凭空判断一段文字的风险。
领域评估器接收事实快照和上一轮局势，返回新的 `Situation`，并可用
`evidence` 解释判断依据。示例演示了如何从来源冲突推导不确定性。

分数范围是 `[0, 1]`，代表应用估计，不宣称是校准概率。
紧迫度、信任和资源压力如何影响执行图由规划器定义；默认约束只处理
最基本的执行边界。
